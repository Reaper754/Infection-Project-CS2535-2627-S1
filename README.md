# Infection!

Build a Python simulation that shows an infection spreading through a moving population. Users will choose simulation settings through a terminal menu. Your program will track results over time, save trial data, and display graphs.

## Getting Started

1. **Read your assignment instructions.** Open the edition for your course. Review its project requirements checklist and rubrics before you begin.
   - [CS25 Assignment](README%20CS25.md) focuses on procedural programming, lists, dictionaries, and file handling.
   - [CS35 Assignment](README%20CS35.md) focuses on object-oriented programming, object relationships, and file handling.
2. **Use the [recommended development process](development_process.md).** Build one part at a time. Test each part before adding the next. CS35 students should use the object design in their assignment wherever the process refers to dictionary-based people.
3. **Use the [How To documents](_Help/How%20To).** These are quick references for the Pygame and Matplotlib features you will need. The numbered files follow the likely development order. Start with [01 - Set Up a Pygame Project from Scratch](_Help/How%20To/01%20-%20Set%20Up%20a%20Pygame%20Project%20from%20Scratch.md) when you are ready to create the simulation window. The BONUS guides provide additional support for the CS35 object design.

## Your First Steps

Start by identifying the settings your user must enter. Build the terminal menu next. This menu is the user's first interaction with your program. It provides options to start a simulation, view previous data, resume or rerun a saved simulation, and exit.

Plan how you will represent each person and the disease before adding graphics. Follow your course's assignment requirements for this design. Then use the development process to add the window, movement, infection rules, saving, and graphs in stages.

Refer back to your assignment checklist as you work. Use the How To examples to understand library features and adapt them to your own program.
